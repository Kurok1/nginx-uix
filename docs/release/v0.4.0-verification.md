## 后端设计与实现证据

- 唯一设计规格为 [`2026-07-20-v0.4-route-lab-design.md`](../superpowers/specs/2026-07-20-v0.4-route-lab-design.md)，以 Nginx 官方 request processing、server_name、location、rewrite 和 access log 语义为基线。
- 静态分析覆盖 listener/default、Host/SNI、exact/wildcard/regex server_name、exact/prefix/`^~`/regex/nested/named location、`merge_slashes` 和 PCRE/RE2 不确定性。不能证明的更高优先级候选不会生成 winner，真实沙箱仍可执行完整可注入候选。
- Agent 只接受固定类型请求和固定根路径；候选在 owner-only stage 中复制、overlay、隔离绝对 include/证书路径、重写 listen/PID/log/temp 并注入稳定 Route ID，启动前对完整候选执行 `nginx -t`。
- HTTP 客户端固定拨号到随机回环端口，不使用代理、redirect、Cookie jar 或 keep-alive；HTTPS 单独保留 SNI。请求正文和敏感 Header 不落库，响应只保留固定 allowlist 与非敏感 `X-*`、受限文本片段、大小和摘要。
- 清理按 process group TERM/KILL、wait/reap、端口关闭和 stage 删除顺序执行；不能证明 master 已回收时保留 owner marker 供启动对账，并以 `ROUTE_CLEANUP_FAILED` 覆盖普通取消或超时。
- migration `0006_route_lab.sql` 保存有界任务、immutable stage、终态结果和安全审计；请求 secret、Body 和敏感 Header 值不进入 SQLite。
- HTTP 提供 workspace 静态分析/入队、历史列表、单次结果、SSE stage 和取消六个 `/api/v1` 操作；全部经过认证、Origin/CSRF、strict JSON、ETag、分页/大小限制与 `no-store`。

## 测试先行与专项回归

实现过程中先取得并确认下列失败，再完成最小修正：

- 嵌套普通 prefix 被外层 regex 覆盖，而嵌套 exact 终止向外回溯。
- 较早的 PCRE-only server/location 候选使静态 winner 为空，但不阻止完整可注入候选入队。
- `merge_slashes off` 保留双斜杠，未知值只返回不确定解释。
- 非敏感 `X-*` 响应头可见，token/key/auth/Cookie 与内部 Header 被移除。
- 取消与成功 settlement 竞态由 durable cancellation 获胜，cleanup failure 覆盖取消/超时。
- unsupported media type、API `no-store`、SSE buffering 和 OpenAPI 契约均有边界测试。
