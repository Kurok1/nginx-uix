执行的关键 Docker 命令：

```sh
IMAGE=nginx-uix:1.1.0-test \
PLATFORM=linux/arm64 \
BUILD_IMAGE=1 \
SMOKE_PROFILE=basic \
tests/docker/smoke.sh

IMAGE=nginx-uix:1.1.0-test \
PLATFORM=linux/arm64 \
BUILD_IMAGE=1 \
WORKSPACE_PROFILE=full \
tests/docker/workspace.sh

MULTIARCH_OUTPUT_DIR=/private/tmp/nginx-uix-v1.1.0-multiarch \
tests/docker/multiarch.sh
```

本机默认 Buildx 使用不支持 OCI exporter 的 `docker` driver，因此多架构命令在一个临时 `docker-container` builder 中执行；Docker daemon 的既有代理只在进程内传给该 builder 和构建步骤。builder 在成功后删除并恢复原选择。第一次 driver 能力失败和两次代理边界 `EOF` 均未进入源码构建成功证据，修正环境后完整命令返回 0。
