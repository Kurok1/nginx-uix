# Nginx UIX v1.1.0 发布说明

v1.1.0 是 v1.0.0 之后的可用性与国际化版本，修复两个已确认的生产缺陷，并为完整管理界面增加简体中文和英语支持。

## 主要变化

### 已发布工作区恢复只读浏览

- 完整性校验通过的 `published` 工作区现在可以再次打开文件树、文件内容、diff 和对应 release。
- 页面读取的是发布时保存的不可变 draft 快照；之后的生产配置变化不会改写历史视图。
- 已发布工作区仍禁止编辑、校验、再次发布或其他写操作。

### CodeMirror 兼容生产 CSP

- SPA 文档的每次响应使用独立随机 CSP nonce，并把同一个 nonce 注入该文档的 CodeMirror 动态样式边界。
- 不启用 `unsafe-inline`，不复用 request ID，也不记录 nonce；随机数生成失败时请求 fail closed。
- 修复生产镜像中编辑器行号、正文和搜索面板因样式被拦截而错位的问题。

### `zh-CN` / `en-US` 全站国际化

- 登录前后均可即时切换简体中文和英语。
- `?lang=zh-CN` / `?lang=en-US` 具有最高优先级，并在站内导航、登录跳转及返回地址中保留。
- 未显式指定时按 `localStorage`、浏览器语言、`en-US` 顺序回退；只持久化非敏感的 `nginx-uix.locale`。
- 全局导航、登录、Dashboard、生效配置、配置工作区、结构化配置、发布与恢复、Route Lab、证书管理以及所有安全确认完成双语覆盖。
- 稳定 API error code 映射为安全的本地化说明，未知或畸形响应使用本地化回退，并继续展示 request ID。
- 日期和数字按当前 locale 格式化；配置、路径、域名、标识符、错误码及外部原始诊断保持原样。

语言选择与回退规则见[语言选择与本地化](https://github.com/Kurok1/nginx-uix/blob/v1.1.0/docs/operations/language-and-localization.md)。

## 依赖与体积

本版本精确锁定 `vue-i18n@11.4.4`。选择原因是它是 Vue 3 的官方国际化方案、v11 仍处于维护周期并使用 MIT 许可证；精确版本锁定也保持 npm 与镜像构建可复现。参考 [Vue I18n 维护策略](https://vue-i18n.intlify.dev/guide/maintenance)、[npm 包信息](https://www.npmjs.com/package/vue-i18n)与[官方发布记录](https://github.com/intlify/vue-i18n/releases)。

使用相同 Node.js 24.17.0、npm 11.13.0 和生产构建命令，对引入国际化前的 `f64974b` 与 v1.1.0 候选进行比较；原始大小使用 `wc -c`、压缩大小使用 `gzip -c | wc -c` 计数：

| 生产资源 | 引入前 | v1.1.0 | 变化 |
| --- | ---: | ---: | ---: |
| JavaScript 原始大小 | 745,453 B | 991,747 B | +246,294 B（+33.0%） |
| JavaScript gzip | 223,196 B | 292,997 B | +69,801 B（+31.3%） |
| CSS 原始大小 | 127,184 B | 128,117 B | +933 B（+0.7%） |
| CSS gzip | 15,344 B | 15,474 B | +130 B（+0.8%） |
| JS + CSS 合计 | 872,637 B | 1,119,864 B | +247,227 B（+28.3%） |
| JS + CSS gzip 合计 | 238,540 B | 308,471 B | +69,931 B（+29.3%） |

该差值包含国际化 runtime、两套完整消息目录和相应产品代码，不能解释为单个依赖的独立体积。v1.1.0 接受这一增量，以换取两种语言的完整首屏与管理流程覆盖；Vite 仍会提示现有主 chunk 超过 500 kB，后续可在不拆散安全关键工作流的前提下单独评估路由级拆包。

## 升级说明

- v1.1.0 不新增 SQLite migration，也不改变 `/etc/nginx` 与 `/var/lib/nginx-uix` 的持久化布局。
- Docker 用户仍应同时备份并挂载上述两个目录，使用固定版本 tag 或 digest 重建容器。
- 本版本不扩大产品边界：仍只管理一体化镜像内部的单节点 HTTP/HTTPS Nginx，不提供 Docker Socket、集群、Kubernetes、WAF 或 Nginx Plus 管理。

完整验证证据见 [v1.1.0 验收记录](https://github.com/Kurok1/nginx-uix/blob/v1.1.0/docs/release/v1.1.0-verification.md)。
