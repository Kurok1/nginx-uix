当前禁止创建正式 tag、GitHub Release 或宣称生产镜像可拉取，原因包括：

- v1.0.0 工作树尚未提交，远端仓库没有 branch、tag 或 GitHub Actions run；
- 当前 `fa5c0127…` source fingerprint 尚未构建；上一镜像只有本地 image ID，`RepoDigests` 为空；
- 上一镜像 revision label 仍是未提交变更所基于的 v0.7.0 commit；
- 没有真实 linux/amd64 runtime 结果；
- 没有 exact v1.0.0 多架构 manifest 的最终 SBOM 和新鲜漏洞扫描；
- 默认分支/rules、registry 权限和正式发布产物尚未完成。
