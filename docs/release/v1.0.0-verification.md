## 发布门禁

v1.0.0 只使用以下四类证据：

1. Go 单元测试通过。
2. 前端 lint、typecheck、单元测试和生产构建通过。
3. native linux/amd64 镜像通过 Docker basic smoke。
4. linux/amd64 与 linux/arm64 的两个程序二进制和 OCI 镜像包构建成功。

Playwright、权限或安全套件、漏洞扫描、SBOM、故障注入、完整升级恢复和长时间稳定性测试不属于本次发布门禁。

## 标准命令

```sh
go mod verify
go test ./...

npm --prefix web ci
npm --prefix web run lint
npm --prefix web run typecheck
npm --prefix web run test
npm --prefix web run build

IMAGE=nginx-uix:1.0.0-test \
PLATFORM=linux/amd64 \
BUILD_IMAGE=1 \
SMOKE_PROFILE=basic \
tests/docker/smoke.sh

tests/docker/multiarch.sh
```

## 发布入口

仓库通过 [`.github/workflows/release.yml`](../../.github/workflows/release.yml) 发布正式版本。推送与 `VERSION` 完全一致的 `vX.Y.Z` tag 后，工作流会：

1. 重跑 Go/前端单元测试、构建与 native amd64 basic smoke。
2. 构建 amd64/arm64 二进制和 OCI 镜像包。
3. 推送 `ghcr.io/kurok1/nginx-uix` 的版本、tag 和 `latest` 多架构镜像。
4. 创建 GitHub Release，并上传二进制压缩包、OCI 镜像包和 `SHA256SUMS`。

`v1.0.0` annotated tag 的 peeled commit 为 `7977774bd04f33b3c097be59064edc2512be67cc`。GitHub Release、五个附件与 GHCR 多架构镜像均已对外发布。
