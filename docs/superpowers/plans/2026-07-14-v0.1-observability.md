# Nginx UIX v0.1.0 Observability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可在 `linux/amd64` 与 `linux/arm64` 上运行的一体化容器，管理员登录后可以安全、只读地查看真实 Nginx 进程状态和同一次 `nginx -T` 实际加载的配置。

**Architecture:** s6-overlay 作为 PID 1，分别监督非 root Web/API、root Unix Socket Agent 与 Nginx；Web/API 使用 SQLite 保存认证元数据，通过固定内部协议查询 Agent；Vue SPA 嵌入 Go Web 二进制。Nginx 配置仍以 `/etc/nginx` 为唯一真源，v0.1.0 不提供任何写入、reload、restart 或路径匹配实验能力。

**Tech Stack:** Go 1.26.4、标准库 HTTP、`modernc.org/sqlite` 1.53.0、Vue 3.5.39、TypeScript 6.0.3、Vite 8.1.4、Vitest 4.1.10、Playwright 1.61.0、npm 11.13.0、Nginx 1.30.3 Debian、s6-overlay 3.2.3.0、Docker BuildKit。
